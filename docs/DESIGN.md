# 制作ノート

## 面白さの分解

Vampire Survivorsから着想を得た核は、移動に集中できる操作、危険な経験値を拾う判断、短周期での能力選択、敵の圧力をビルドで覆す成長、シナジーが連鎖した瞬間の解放感。武器のバリエーションを増やすだけでは、その判断の構造は変わらない。

LOOMFALLは、陣取り・図形を閉じる遊びを移動そのものに統合した。安全な方向にただ逃げると細い糸しか描けない。敵を誘い、回り込み、退路を選ぶと、広い領域になる。閉じる時点も手動なので、密度と広さと残り生命を見て判断する。糸の長さには上限があり、始点は古い頂点から移動する。

領域は敵と経験値を同時に収穫し、複数撃破で回復する。自動攻撃は逃げ道を開き、減速する糸は敵を溜め、領域は成長の資源になる。一つの移動と戦闘の循環にすべてを結びつけた。SPACEで最初と最後の点をつなぐため、完全な一周を走り切る必要はない。狭すぎる領域は近距離衝撃波に変換して、失敗した入力にも最低限の応答を残す。

## 戦略の差

- 領域と雷：長い糸、結びの威力、残響、雷の撃破連鎖。群れを誘い込み、一度にほどく。
- 針と毒：多連射、貫通、毒の伝播、衛星。接近前に崩し、領域で取り残しを回収。敵を倒す速度が速いぶん、結びでの回復機会は少なくなる。
- 持続する庭：霜、長い残響、二重結び、頂点からの結晶針。移動経路に安全な領域を重ねる。

進行中の3択と限られた強化回数で、毎回異なる配合になる。9試行中、領域3/3、針1/3、庭3/3がクリア。これは決定的な全体勝率の推定ではなく、固定の操作方針と3つの乱数に限った検証結果。

## 実装後の改善

1. 初期版は自動針が敵を倒しすぎた。通常敵の生命と密度を増やし、自動攻撃の射程を縮め、糸の接触効果を小ダメージと減速に変更。
2. 境界ぎりぎりの敵を囲んでも外れる不快感に対し、領域の縁34pxと敵半径も捕獲判定に含めた。
3. 領域による撃破の経験値を直接吸引。3体以上を倒す結びには基礎回復を付け、危険を冒す価値を作った。
4. 初期の経験値曲線では全強化を取り切って同じビルドになった。必要経験値の二次項を増やし、終盤37〜40レベル程度で選択の差を維持。
5. 針主体の構成が弱かったため、毒撃破時の近接伝播とLv.5月針の追加貫通を導入。連鎖の再帰には制限を設けた。
6. プレビューの点線、糸の始点、範囲面積、結びのクールダウン、敵弾と経験値の異なる輪郭、ボスの突進予告を追加。
7. 花の明度と不透明度を下げ、背景より敵・糸を読み取りやすくした。被弾の無敵時間、シェイク軽減、タッチボタン、画面非表示時の自動ポーズを整備。
8. 終盤の負荷測定後、庭園の装飾を静的Canvasに事前描画。領域に境界ボックス判定を追加し、文字の個別ブラーを除去。空間グリッド、描画カリング、粒子上限、敵240体上限も使用。

## 制約

ブラウザの実操作とフレーム測定は自動操作で行った。人間の長時間プレイによる手触り評価、幅広い端末での検証、外部プレイテストは未実施。BGMはWeb Audioによるオリジナルの生成音楽で、商用サンプルや既存曲は使用していない。
